# 毎日の食事記録アプリ

料理写真をスマホで撮って記録すると、Anthropic (Claude) の画像認識でカロリー・タンパク質・脂質・炭水化物・塩分を自動推定する、個人利用向けのPWA(Progressive Web App)です。血圧・体重記録アプリ(`claude/blood-pressure-dialysis-app-f4ayhy`ブランチ)と同じ方式(サーバー不要の静的PWA)で作られています。

## 特徴

- 料理写真をアップロードすると、AIがカロリー・タンパク質・脂質・炭水化物・塩分を自動推定
- 日付ごとの記録一覧とその日の合計栄養価を表示
- スマホのホーム画面にアイコンを追加してアプリのように起動可能(PWA)
- 記録データ(数値・写真)は端末内(ブラウザのIndexedDB)に保存
- メニューからJSON形式でのエクスポート/インポートに対応(機種変更時のデータ引き継ぎ用)

## 重要: 血圧記録アプリとの違い(データの送信について)

血圧記録アプリはデータをすべて端末内に保存し、サーバーには一切送信しません。
このアプリは**写真の解析のためにAnthropicのサーバーへ画像を送信します**。具体的には次の通りです。

- 解析に使うAPIキーは、この端末のブラウザ内(localStorage)にのみ保存されます
- 「設定」で入力したAPIキーと写真は、解析のたびにブラウザから直接 `https://api.anthropic.com` へ送信されます(このアプリ自身のサーバーは存在せず、経由もしません)
- **共有端末や他人と共有するURLでは、自分のAPIキーを入力しないでください**。ブラウザの開発者ツール等からAPIキーが見える状態になります
- 個人の端末で、自分のAPIキーを使って利用することを想定しています

## 使い方(ローカルで動かす)

サービスワーカーやカメラ入力を正しく動かすため、`file://` で直接開かず、簡易サーバー経由で開いてください。

```bash
cd webapp
python3 -m http.server 8000
```

ブラウザ(スマホ推奨)で `http://<PCのIPアドレス>:8000/index.html` を開きます。

初回起動後、右上の「⋮」メニュー → 「APIキー設定」から Anthropic の APIキー([console.anthropic.com](https://console.anthropic.com/)で発行)を入力してください。

## スマホのホーム画面にアイコンを追加する

- **iPhone(Safari)**: 共有ボタン → 「ホーム画面に追加」
- **Android(Chrome)**: メニュー(⋮) → 「ホーム画面に追加」/「アプリをインストール」

追加すると、専用のアイコンからアプリのようにフルスクリーンで起動できます。

## 公開(GitHub Pages)について

このリポジトリでは血圧記録アプリ(`claude/blood-pressure-dialysis-app-f4ayhy`ブランチ)がすでにGitHub Pagesに公開されています。GitHub Pagesは1リポジトリにつき公開サイトが1つのため、このアプリを同じ方法で自動デプロイすると血圧記録アプリの公開ページを上書きしてしまいます。そのため、このブランチには自動デプロイ用のGitHub Actionsワークフローをあえて追加していません。

両方のアプリを同時に公開したい場合は、将来的に次のいずれかの対応が必要です。

- 両アプリを1つのデプロイ設定にまとめ、`/meal/`・`/health/` のようなサブパスで公開する
- どちらかを別のリポジトリ、または別のホスティング先(Render・Netlifyなど)に分けて公開する

## 注意

- PWAのインストールやカメラでの画像取り込みには HTTPS(または localhost)での配信が必要です
- データは端末のブラウザ内にのみ保存されます。ブラウザのデータを消去すると記録も消えるため、定期的に「エクスポート」でバックアップを取ることをおすすめします
- 栄養価はAIによる概算です。医療的・専門的な判断には使用しないでください
