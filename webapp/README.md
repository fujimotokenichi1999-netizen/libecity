# 健康記録(血圧・体重・血液検査記録アプリ)

血圧・体重・血液検査結果の画像をスマホで記録できる、個人利用向けのPWA(Progressive Web App)です。

## 特徴

- 血圧を1日に何回でも記録(上/下/脈拍/メモ)
- 体重の記録(日々の変化をグラフで確認)
- 毎月の血液検査結果を写真として取り込み・一覧閲覧
- 血圧・体重の推移グラフ
- スマホのホーム画面にアイコンを追加してアプリのように起動可能(PWA)
- データはすべて端末内(ブラウザのIndexedDB)に保存。サーバーには送信されません
- メニューからJSON形式でのエクスポート/インポートに対応(機種変更時のデータ引き継ぎ用)

## 使い方(ローカルで動かす)

サービスワーカーやカメラ入力を正しく動かすため、`file://` で直接開かず、簡易サーバー経由で開いてください。

```bash
cd webapp
python3 -m http.server 8000
```

ブラウザ(スマホ推奨)で `http://<PCのIPアドレス>:8000/index.html` を開きます。

## スマホのホーム画面にアイコンを追加する

- **iPhone(Safari)**: 共有ボタン → 「ホーム画面に追加」
- **Android(Chrome)**: メニュー(⋮) → 「ホーム画面に追加」/「アプリをインストール」

追加すると、専用のアイコンからアプリのようにフルスクリーンで起動できます。

## 注意

- PWAのインストールやカメラでの画像取り込みには HTTPS(または localhost)での配信が必要です。実際のスマホから使う場合は、GitHub Pages などHTTPSで配信できるホスティングサービスにこの `webapp` フォルダを公開してください。
- データは端末のブラウザ内にのみ保存されます。ブラウザのデータを消去するとログも消えるため、定期的に「エクスポート」でバックアップを取ることをおすすめします。
- 医療的な判断はできません。あくまで記録・可視化のためのツールです。
